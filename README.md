# Python Calculator

## About This Project
A command-line calculator built with Python that performs basic 
arithmetic operations including addition, subtraction, 
multiplication, and division.

## Why I Built This
I am an 18-year-old Computer Science aspirant from Sri Lanka 
teaching myself programming independently alongside my Advanced 
Level studies. This calculator is one of my Python projects, 
built to strengthen my programming fundamentals.

## Features
- Addition
- Subtraction
- Multiplication
- Division

## Technologies Used
- Python 3

## How to Run
1. Make sure Python is installed on your computer
2. Download the file `calculator.py`
3. Open terminal and run:
   python calculator.py
4. Follow the on-screen instructions
